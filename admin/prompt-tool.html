AI 작업용 프롬프트 복사 도구 (독립 실행 버전)

이 페이지는 Sveltia CMS 화면(/admin/) 안에 뜨는 도구가 자동으로 값을 못 채웠을 때 쓰는 안전한 대체 화면입니다. 어떤 AI 모델도 직접 호출하지 않으며, 클립보드 복사 외에는 아무 것도 자동으로 저장하거나 발행하지 않습니다.

1. 기사 불러오기 (선택 사항)

비공개 저장소이므로 로그인 토큰이 없으면 자동 로딩이 실패할 수 있습니다. 그 경우 아래 항목에 직접 원문/메타데이터/초안을 붙여넣어 사용하세요.

2. 포함할 항목 선택
3. 원문 메타데이터
4. 원문 본문 (읽기 전용 원문 그대로 붙여넣기)
5. 현재 편집 초안

복사한 내용은 여러분이 직접 사용하는 AI 채팅 도구에 붙여넣어 확인하세요. AI가 만든 결과는 반드시 사실 여부를 검토하고, 원문에 없는 내용(추측/과장/없는 통계·인용)은 그대로 받아들이지 마세요. 이 페이지는 어떤 모델도 대신 호출하지 않습니다. 사용법 상세는 ai-prompt-copy.manual-test.md를 참고하세요.
