개인정보 수집 및 이용 안내

이 뉴스레터는 공개 구독 신청을 받지 않습니다. 수신인은 운영진이 직접 추가한 사람만 해당하며, 아래와 같이 개인정보를 수집·이용합니다.

수집 항목

이메일 주소 (운영진이 직접 입력)

이용 목적

월간 뉴스레터 발송. 수신인마다 테스트 발송 대상 여부와 실제 발행 발송 대상 여부를 별도로 관리하며, 실제 발행 발송 대상으로 표시되지 않은 주소에는 정식 뉴스레터가 발송되지 않습니다.

보유 기간

운영진이 수신 목록에서 삭제할 때까지 보유합니다. 수신을 원하지 않으시면 아래 문의처로 알려주시면 즉시 삭제합니다.

처리 방식

수신인 이메일 주소는 비공개 Git repository(swebin-newsletter-data)에만 저장하며, 운영을 위임받은 관리자만 GitHub 계정 권한으로 접근·수정할 수 있습니다. 관리 화면 자체는 검색엔진에 노출되지 않으며 공개적으로 안내되지 않고, 접근이 필요한 관리자에게만 개별적으로 주소가 전달됩니다. 별도의 공개 구독/수신거부 API는 존재하지 않습니다. 목록에서 삭제하는 것 자체가 수신 거부이며, 다음 발송부터 즉시 반영됩니다. Git의 과거 변경 이력에는 이전 버전이 남을 수 있습니다.
