운영 관리

이 페이지는 비개발자 운영자가 콘텐츠·수신인·발송·공개 상태를 확인하고 필요한 작업으로 이동하는 안내 화면입니다. 비공개 데이터(수신인 이메일, 발송 기록, SMTP 정보 등)는 이 페이지에 절대 표시되지 않습니다. 이 화면 자체도 공개 사이트 어디에서도 링크되지 않으며, 이 주소를 아는 사람만 열어볼 수 있습니다. 실제 대시보드 내용은 GitHub 로그인 후에만 불러옵니다.

대시보드 내용은 공개 사이트나 이 페이지의 소스에 저장되어 있지 않으며, GitHub 로그인 후 비공개 저장소에서 직접 불러옵니다. 위 버튼으로 로그인해 주세요.
