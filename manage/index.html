운영 관리

이 페이지는 콘텐츠 편집, 수신인/발신인 관리, 발송 기록 확인으로 가는 안내 화면입니다. 아래 링크는 모두 GitHub 로그인을 요구하며, 해당 저장소에 접근 권한이 있는 계정만 실제로 내용을 보거나 수정할 수 있습니다. 비공개 데이터(수신인 이메일, 발송 기록 등)는 이 페이지에 표시되지 않습니다.

수신인 · 발신인 관리

뉴스레터를 받을 사람 추가/삭제, 발신 프로필(From 주소, SMTP 설정 등) 관리. SMTP 비밀번호는 여기서 다루지 않습니다 -- 새 발신 계정 추가는 기술 관리자가 GitHub Secret을 먼저 설정해야 합니다.

발송

테스트 발송과 실제 발송은 GitHub Actions에서 실행됩니다 (저장소 Actions 탭 → 원하는 workflow → Run workflow). 실제 발송은 이슈 ID와 정확히 일치하는 확인 문구를 직접 입력해야만 실행되는 의도된 이중 확인 절차입니다.
