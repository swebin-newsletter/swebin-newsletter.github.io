발송 안내

이 페이지는 발송을 직접 실행하는 도구가 아니라, 발송이 실제로 어떻게 이루어지는지에 대한 안내입니다. 테스트 발송과 실제 발송은 모두 swebin-dev/swebin-newsletter 저장소의 GitHub Actions에서만 실행되며, 웹에서 클릭 한 번으로 발송을 트리거하는 별도 화면은 존재하지 않습니다.

테스트 발송

Actions 탭 → Send test email workflow → Run workflow. 이슈 ID와 발신 프로필, 실제 받을 이메일 주소를 직접 입력해야 실행됩니다.

실제 발송

Actions 탭 → Send newsletter workflow → Run workflow. 발송할 이슈 ID와 정확히 일치하는 확인 문구를 직접 입력해야만 실행되는 의도된 이중 확인 절차입니다. 수신 대상은 그 시점의 data/recipients.json이며, /admin-recipients/에서 관리자가 미리 확정해 둔 목록만 사용됩니다.

발송 중단 시

중간에 실패하거나 중단된 발송은 Resume newsletter workflow로 이어서 진행합니다. 실행 결과와 수신인별 발송 상태는 비공개 데이터 저장소의 data/send-runs/ 아래에 기록되며(저장소 이름과 위치는 보안상 공개하지 않습니다), 공개 사이트에는 노출되지 않습니다.

권한이 없다면

위 workflow들은 저장소에 쓰기 권한이 있는 GitHub 계정만 실행할 수 있습니다. 권한이 필요하면 swebin.newsletter@gmail.com로 문의해 주세요.
